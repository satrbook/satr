# سطر — مكتبة رقمية على GitHub Pages

1. أنشئ مستودعًا جديدًا وارفع كل ملفات هذا المجلد إلى جذره.
2. Settings ← Pages ← Source: Deploy from a branch ← main ← / (root).
3. افتح `https://USERNAME.github.io/REPO/admin.html` لإدارة المحتوى.
4. للنشر من لوحة التحكم: أنشئ Fine-grained token لهذا المستودع فقط بصلاحية Contents (Read and write)، وضعه في تبويب «النشر».
